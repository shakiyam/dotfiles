# Hunk Review

1. Bashで `hunk session list` を実行し、現在のリポジトリのセッションがあるか確認する。ない場合、ステージ直後なら何もせず終える。頼まれたときは起動を頼んで止まる。
2. Bashで `hunk skill path` を実行し、hunk本体に同梱されたSKILL.mdのパスを取得して読み込む。
3. ステージ直後は表示内容を切り替えず、表示されている差分に注釈を付ける。
4. 同梱の手順に従ってレビューする。注釈は意図が自明でない変更にだけ付ける。
