# Hunk Review

1. Bashで `hunk session list` を実行し、現在のリポジトリのセッションがあるか確認する。ない場合、ステージ直後なら何もせず終える。頼まれたときは、ユーザーにhunkの起動を頼んで止まる。ただし、hunk 0.23.0以前では、Claudeが注釈を付けたファイルが差分から消えると登録が外れる(modem-dev/hunk#1138)。そのため、セッションがなくても現在のリポジトリをcwdとする `hunk diff` のプロセスがあれば、どちらの場合も登録が外れている旨を伝えて再起動を頼む。
2. Bashで `hunk skill path` を実行し、hunk本体に同梱されたSKILL.mdのパスを取得して読み込む。
3. ステージ直後は表示内容を切り替えず、表示されている差分に注釈を付ける。内容が古くなった自分の注釈は、`hunk session comment rm` で消す。ユーザーの返信が付いていて消せない場合は、古くなったことと今の内容を返信で伝える。
4. 同梱の手順に従ってレビューする。注釈は意図が自明でない変更にだけ付ける。
5. 注釈を付けた後、このファイルと同じディレクトリにある `watch-notes.sh <リポジトリ>` を、Bashの `run_in_background` で起動する。このスクリプトは、コミットを検知すると注釈とノートをすべて消し、ユーザーが新しいノートを書くと出力して終わる。終わったら、出力されたノートを読んで返答し、再び起動する。セッションがなくなって終わった場合は、再び起動しない。ほかの理由で終わった場合は、hunkのエラーをユーザーに伝える。
