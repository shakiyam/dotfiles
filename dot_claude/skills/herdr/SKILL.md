# Herdr

1. Bashで `herdr --skill` を実行し、herdr本体に同梱されたSKILL.mdを読み込む。`herdr --version` で版も確かめる。
2. 同梱の手順に従って操作する。ただし、herdr 0.9.5では次の問題を確認している。版が0.9.5より新しい場合は、これらの問題が直っているかもしれないことをユーザーに伝える。
   - `agent wait` と `agent prompt --wait` は、エージェントが作業中でも `idle` を返すことがある。完了は、指示した区切り行が出力に現れたか、エージェントからの返信が届いたかで判定する。
   - Claude Codeの入力欄に、次の指示の提案文が表示されていることがある。Enterだけを送ると、それが送信されるおそれがある。
